# 个人修炼状态系统开发流程计划书

## 0. 项目目标

本项目要在本地开发一个 Web 应用，用游戏化数值系统管理个人学习、事件试炼和审美游历。

核心结构：

```text
门派 -> 功法 -> 知识点 -> 修炼记录 -> 数值成长 -> 境界突破
```

核心属性：

```text
法力：练习、解题、执行能力
神识：笔记、思考、体系化理解
神魂：阅读、电影、番剧、游戏剧情等审美体验后的总结积累
```

开发方式：

```text
一边学 Web 开发，一边完成项目。
每一步只解决一个明确问题。
每一步都要能运行、能看到结果、能记录进度。
```
